# poet_okjeong
프로젝트명: 시인과의 인터뷰 (Interview with Poets)
중학생들이 한국 문학사 속 거장들과 실시간으로 대화하며 문학을 깊이 있게 이해할 수 있도록 제작된 생성형 AI 기반 교육용 웹 플랫폼입니다.

주요 특징:

Google Gemini API를 활용한 역사적 시인 페르소나 챗봇 구현

Google Apps Script 및 구글 시트를 연동한 학생별 대화 내용 자동 아카이빙

학번 5자리 유효성 검사 및 모바일 최적화 반응형 UI 디자인

시인 선택 시 은은하게 나타나는 배경 워터마크 효과 적용
